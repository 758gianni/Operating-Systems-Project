# OS Project

Simple C programs for common operating systems and process-management exercises.

## Project Files

- `main_menu.c` - Menu-driven entry point for running project tasks.
- `factorial.c` - Factorial-related process/task example.
- `fork_tasks.c` - Fork/process creation task examples.
- `sorting.c` - Sorting task implementation.

## Build

Compile each source file with `gcc`:

```bash
gcc main_menu.c -o main_menu
gcc factorial.c -o factorial
gcc fork_tasks.c -o fork_tasks
gcc sorting.c -o sorting
```

## Run

Run any compiled binary:

```bash
./main_menu
```

Use the binary name for the task you want to execute (for example, `./factorial`, `./fork_tasks`, or `./sorting`).
